# Python-1

Repositorio creado en 2026 para recopilar y versionar las prácticas, talleres y exámenes de Python que desarrollé originalmente en local durante el curso 2025–2026, de septiembre a marzo.

Durante el curso no trabajaba con Git, todo lo hacía en local. Al subirlo he reconstruido el historial a partir de las fechas de los archivos, para que se vea más o menos cuándo hice cada cosa y no el día en que lo subí, así que las fechas de los commits son aproximadas.

## Contenido

- `t1 ejercicios/` – tema 1: variables, cadenas, condicionales y bucles
- `t3/ejemlos/` – tema 3: funciones, parámetros y ejercicios
- `t4/` – tema 4: listas, mapas, clases, excepciones, ficheros y CSV
- `t4 ejer/` – ejercicios del tema 4 con el Quijote (incluye los capítulos separados)
- `Examen1/`, `Examen2/`, `Examen3/` – exámenes
- `Taller1.py`, `Taller2/`, `Taller3/` – talleres
